Restaurer la base

Remplace tout le contenu de la base par celui d'un fichier produit par « Export JSON » (barre latérale). Les identifiants du fichier sont conservés : liens et adresses des fiches redeviennent ceux de la sauvegarde.

Les données actuelles absentes du fichier sont perdues. En cas d'erreur, rien n'est modifié. Les exports d'un seul type (bouton « Export JSON » d'une liste) sont refusés.
